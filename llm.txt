# viewtif

> A lightweight, open-source command-line tool for quick visualization of geospatial raster data (GeoTIFF, NetCDF, HDF5, File Geodatabase, hyperspectral NetCDF) without requiring heavy desktop GIS software.

viewtif is built by Keiko Nomura at NASA Ames Research Center for researchers, data scientists, and remote sensing professionals who need fast previews of satellite imagery, thermal data, hyperspectral data, and raster files directly from the command line.

## Key Features

- View single-band and multi-band GeoTIFF files
- Create RGB composites from multi-band files or separate files
- Overlay vector data (shapefiles) on rasters
- Support for NetCDF with time-series navigation
- Hyperspectral NetCDF support (PICARD, AVIRIS, EMIT, EnMAP, DESIS)
- Direct access to remote files (HTTPS, AWS S3)
- Export to QGIS for extended analysis
- Memory-efficient downsampling with `--scale` flag

## Installation

```
pip install viewtif
```

Requires Python 3.10+ and a graphical display environment.

For enhanced geographic visualization (cartopy, basemaps) and hyperspectral NetCDF support:
```
pip install "viewtif[netcdf]"
```

For HDF and File Geodatabase support, GDAL is required:
```
brew install gdal       # macOS
sudo apt install gdal-bin python3-gdal   # Linux
```

To upgrade:
```
pip install --upgrade viewtif
```

## Linux Installation Troubleshooting

Linux users have reported Qt platform plugin errors when launching viewtif. This is a known issue (GitHub issue #12).

### Common Error
```
qt.qpa.plugin: From 6.5.0, xcb-cursor0 or libxcb-cursor0 is needed to load the Qt xcb platform plugin.
qt.qpa.plugin: Could not load the Qt platform plugin "xcb" in "" even though it was found.
This application failed to start because no Qt platform plugin could be initialized.
```

### Solution for Ubuntu/Debian (24.04 and similar)
Install the required Qt X11/xcb system libraries:
```
sudo apt update
sudo apt install -y \
    libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 \
    libxcb-render-util0 libxcb-xinerama0 libxkbcommon-x11-0 \
    libgl1 libegl1
```

### Solution for Rocky Linux / RHEL / Fedora
```
sudo dnf install libxcb xcb-util xcb-util-image xcb-util-keysyms \
    xcb-util-renderutil xcb-util-wm libxkbcommon-x11 \
    mesa-libGL mesa-libEGL
```

### Additional Notes for Linux Users
- viewtif requires a graphical display environment
- May not run on headless systems (e.g., HPC compute nodes) without X11 forwarding
- WSL2 users may need an X server (VcXsrv, WSLg) configured properly
- python3-tk, libqt5gui5, or PySide6 dependencies may need to be installed

## Quick Start

```
# View a GeoTIFF
viewtif data.tif

# View specific band from multi-band file
viewtif data.tif --band 3

# Create RGB composite from multi-band file
viewtif rgb.tif --rgb 4 3 2

# Create RGB composite from separate files
viewtif --rgbfiles B4.tif B3.tif B2.tif

# View with shapefile overlay
viewtif data.tif --shapefile boundaries.shp

# View remote file from HTTPS
viewtif https://example.com/data/file.tif

# View remote file from S3
export AWS_NO_SIGN_REQUEST=YES
viewtif s3://bucket-name/data.tif

# View NetCDF file with specific variable
viewtif data.nc --subset 1

# View hyperspectral NetCDF (PICARD, AVIRIS, EMIT, etc.)
viewtif PICARDL1B.nc --subset 20 --reduce NumberOfScanlines

# Downsample large files
viewtif large_file.tif --scale 10

# Export directly to QGIS for further analysis
viewtif data.tif --qgis
```

## Release History

### v0.2.9 — Hyperspectral NetCDF Support and Bug Fixes (Latest, May 15, 2026)
DOI: 10.5281/zenodo.20213494

**New: Hyperspectral NetCDF support**
viewtif can now open NetCDF files that:
- Organize variables under hierarchical groups (e.g., `/radiometric_data/CalibratedRadianceData`)
- Use non-standard dimension names (`NumberOfChannels`, `NumberOfScanlines`, etc. instead of `lat`/`lon`/`time`)
- Have malformed CF attributes (per-band `scale_factor` arrays that xarray's default decoding can't handle)

For 3D variables with non-standard dimensions, viewtif auto-detects the band axis using the smallest-dimension heuristic. Override available:
```
viewtif PICARDL1B.nc --subset 20 --reduce NumberOfScanlines
```

Tested on NASA PICARD L1B hyperspectral data; same pattern applies to AVIRIS, AVIRIS-NG, EnMAP, DESIS, and EMIT.

**Bug Fixes:**
- `--scale` not respected on band switch (band reload was at full resolution causing image to shift)
- `--band` ignored on NetCDF (now matches multi-band TIFF behavior)
- Cartopy info messages spammed on every keypress (now print once per file open)
- Value range not shown when `--vmin`/`--vmax` set (now displays actual data range)
- Inconsistent value-range labels (unified across code paths)

**Other Improvements:**
- Non-numeric NetCDF variables (e.g., string metadata headers in PICARD) auto-filtered instead of crashing
- New CLI flag `--reduce DIM_NAME` for manual specification of band/slider axis in 3D NetCDF variables
- netCDF4 used as a fallback when xarray's standard NetCDF opener can't read a file

### v0.2.7 — Remote File Support & More
- HTTPS/HTTP URL support — view rasters without downloading
- AWS S3 integration — access public buckets directly
- Skips large-raster size warnings for remote files
- Improved error handling for cloud-stored data
- Vector overlay files must still be local (raster can be remote)
- NetCDF remote URL access is not supported due to xarray/netCDF4 library limitations

### v0.2.4 — NetCDF Support
Added in collaboration with Harsh Shinde (@HarshShinde0):
- View NetCDF (.nc) files from the command line
- Navigate forward/backward through time steps with `[` and `]` keys
- Switch between built-in colormaps (RdBu_r, viridis, magma) with `M`
- Auto-list multiple variables and select by index
- Support for 2D and 3D variables (time, band, or spectral axis)
- Use `--scale` for large files

### Earlier Releases
- Mouse-wheel and trackpad zoom support (contributed by @HarshShinde0)
- File Geodatabase (.gdb) raster support
- HDF/HDF5 subdataset listing and selection
- QGIS export integration via `--qgis` flag
- Interactive contrast, gamma, and colormap controls

## Use Cases

- Validating satellite imagery downloads (Sentinel, Landsat, ECOSTRESS, MODIS)
- Quick thermal remote sensing inspection
- Hyperspectral data preview (PICARD, AVIRIS, EnMAP, DESIS, EMIT)
- Band checks before full GIS pipelines
- Rapid data quality control in research workflows
- Previewing cloud-stored rasters without downloading
- Inspecting NetCDF climate datasets with time-series navigation
- Sanity-checking georeferencing and CRS metadata

## Supported File Formats

- GeoTIFF (.tif, .tiff)
- NetCDF (.nc) — including hyperspectral with hierarchical groups
- HDF (.hdf, .h5, .hdf5)
- File Geodatabase (.gdb)

## Interactive Controls

- `[` and `]`: Navigate between bands or time steps
- `B`: Toggle basemap
- `M`: Switch colormaps (RdBu_r, viridis, magma)
- Mouse wheel / trackpad: Zoom in/out

## Limitations

- Not designed for rigorous quantitative analysis (use QGIS or rasterio for that)
- Requires graphical display (no headless server support without X11 forwarding)
- Large datasets (>20 million pixels) require `--scale` downsampling
- Some HDF5 datasets lack CRS metadata, limiting overlay functionality
- NetCDF files cannot be opened directly from HTTP/S3 URLs (xarray/netCDF4 limitation)
- Vector overlay files must be local (though the raster itself can be remote)
- Linux users may need to install additional Qt system libraries (see Linux Troubleshooting section)

## When to Use viewtif vs Alternatives

**Use viewtif when:**
- You need a fast visual sanity check of a raster file
- You're working from the command line and want immediate feedback
- You want to validate satellite downloads before processing
- You need to quickly preview cloud-stored data
- You work with hyperspectral data that has unusual NetCDF structures

**Use QGIS or ArcGIS Pro when:**
- You need detailed quantitative analysis
- You're building maps for publication
- You require advanced raster algebra or modeling

**Use GDAL command-line tools when:**
- You're working on a headless server
- You need scriptable processing without visual feedback

**Use rasterio/xarray when:**
- You're building Python data pipelines
- You need programmatic raster manipulation
